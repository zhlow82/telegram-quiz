========================================================
  TELEGRAM QUIZ - SETUP GUIDE (Mac)
  How to install and run the system on your computer
========================================================


--------------------------------------------------------
  WHAT YOU NEED
--------------------------------------------------------

  1. Docker Desktop for Mac (free) - Download from docker.com
  2. The project folder (telegram-quiz.zip)
  3. An internet connection (needed for the first start
     only, to download the required images)

  That's it! No Java, no Node.js, no database installation needed.
  Docker handles everything automatically.

  Works on both Apple Silicon (M1/M2/M3) and Intel Macs -
  Docker Desktop installs the right version automatically.


--------------------------------------------------------
  STEP 1: Install Docker Desktop
--------------------------------------------------------

  1. Open your browser and go to: docker.com/products/docker-desktop
  2. Click "Download Docker Desktop" (Mac version)
  3. Open the downloaded .dmg file and drag the Docker
     icon into your Applications folder
  4. Open Docker Desktop from Applications
  5. If asked, grant the required permissions and restart
     if prompted
  6. Wait until the whale icon appears in the menu bar
     (top-right corner of your screen)

  [Insert screenshot: Docker Desktop whale icon in menu bar]


--------------------------------------------------------
  STEP 2: Extract the Project
--------------------------------------------------------

  1. In Finder, locate telegram-quiz.zip
  2. Double-click it - macOS extracts the folder automatically
  3. You now have a telegram-quiz folder

  [Insert screenshot: telegram-quiz.zip in Finder]


--------------------------------------------------------
  STEP 3: Start the Services
--------------------------------------------------------

  1. Open Terminal:
     - Press Cmd + Space, type "Terminal", press Enter
     - Or find it in Applications > Utilities > Terminal

  2. Navigate to the extracted folder:

       cd ~/Downloads/telegram-quiz

     Tip: you can type "cd " (with a space) and then drag the
     telegram-quiz folder from Finder into the Terminal
     window, then press Enter.

  3. Make the scripts executable (one time only):

       chmod +x start.sh stop.sh

  4. Start the services:

       ./start.sh

  5. The first start takes a few minutes (it downloads
     and builds everything). Later starts are much faster.
  6. Wait for the "Telegram Quiz - Ready!" message

  [Insert screenshot: ./start.sh running with success message]


--------------------------------------------------------
  STEP 4: Access the Application
--------------------------------------------------------

  1. Open your browser (Safari, Chrome, etc.)
  2. Go to: http://localhost/tg-quiz
  3. Log in with the credentials below

  Default Admin Login:
    Username: localadmin
    Password: password88

  IMPORTANT: After your first login, open My Profile
  (click your name in the bottom-left corner) and change
  the password. The default password is public.

  [Insert screenshot: Login page at http://localhost/tg-quiz]


--------------------------------------------------------
  STOPPING AND STARTING AGAIN
--------------------------------------------------------

  When you're done, stop the services. In Terminal (from
  the project folder) run:

      ./stop.sh

  This stops all services but keeps your data safe
  (quizzes, questions, users). Containers are kept, so the
  next start is fast.

  To start again, just run ./start.sh again.

  [Insert screenshot: ./stop.sh in Terminal]


--------------------------------------------------------
  TROUBLESHOOTING
--------------------------------------------------------

  Docker not running?
    - Make sure Docker Desktop is open
    - Wait for the whale icon in the menu bar
    - Check System Settings > Privacy & Security if a
      permission warning appears

  Permission denied when running ./start.sh?
    - Run chmod +x start.sh stop.sh first (see Step 3)

  Port already in use?
    - Make sure no other app is using port 80
    - Close other web servers or apps using port 80

  Services not starting?
    - Open Docker Desktop to check container status
    - Make sure you have an internet connection on the first start

  Forgot the admin password?
    - Delete the containers and volumes, then start again:
      docker compose down -v

  Need help?
    - Contact your system administrator
